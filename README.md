# الحقوق المشتركة بين الزوجين

عرض تقديمي تفاعلي لدرس «الحقوق المشتركة بين الزوجين» · أحكام الأسرة والزواج في الإسلام · دين 201 · ثاني ثانوي.

An interactive lesson deck (27 slides, Arabic, right to left) built with reveal.js in the «ورق وحبر» (Paper & Ink) style.

## افتحي العرض · Open it

1. نزّلي المجلد (Code ← Download ZIP) وفكّي الضغط.
2. افتحي الملف `deck/index.html` بمتصفح **Chrome**.
3. استخدمي المفاتيح:

| المفتاح | الوظيفة |
|---|---|
| → / ← | التالي / السابق |
| F | ملء الشاشة |
| T | بدء أو إيقاف المؤقّت (أو انقري على الدائرة) |
| 1–4 | اختيار إجابة في مهمة المحقِّقة (أو انقري عليها) |

Keep the `assets` folder next to `index.html`. No internet connection or installation is needed.

## With Claude Code

Open this folder in Claude Code and say **"run the presentation"**. Instructions for Claude are in [CLAUDE.md](CLAUDE.md), including how to edit slides and rebuild.

## What's inside

Title · class agreement · secret-student award · a journey back through history · divorce statistics · lesson objectives · **Activity 1:** the leaked chat, the detective quiz and the four missing rights · evidence for each right · assessment 1 · **Activity 2:** the courtroom case file, three more shared rights with their evidence, roles and verdict · "if you were a counsellor" · AI needs your help · assessment 2 · homework · closing activity · summary.

## Sources and credits

- Lesson content: the teacher's original slides and the course textbook (pp. 69–74).
- Statistics: registered divorce cases in Bahrain, 2001–2021, from the [Bahrain Open Data Portal](https://www.data.gov.bh/explore/dataset/divorce-cases/) (Ministry of Justice, Islamic Affairs and Waqf).
- Fonts: Noto Kufi Arabic, IBM Plex Sans Arabic, Amiri (SIL Open Font Licence).
- Built with [reveal.js](https://revealjs.com).

**Before teaching:** every verse and hadith was typed from the textbook and should be proofread by the teacher.
